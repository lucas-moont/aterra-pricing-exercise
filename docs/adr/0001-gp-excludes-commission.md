# GP excludes commission — we diverge from the reference screen on purpose

The founder's reference screen computes GP as `Client Pays − (Cost + VAT)`, which
folds the agent's commission into gross profit ($176 / 23.7% on the Hemingways
line). The brief's formula defines GP as `DMC RECEIVES − (Cost + VAT)`
($101.69 / 15.3%) — commission is the agent's money and is never the DMC's.

We follow the brief: **GP excludes commission.** The numbers on our screen will
not match the founder's reference, and that is intentional, not a bug. "Pixel
perfect" applies to layout, typography, colour and spacing only — never to
reproducing a calculation error. A pricing screen that is subtly wrong is worse
than no pricing screen, so correctness wins over visual fidelity to the mock.

The next engineer will be tempted to "fix" our GP to match the founder's mock.
Do not. This is called out in the submission note so the reviewers see it as a
deliberate judgment call.
